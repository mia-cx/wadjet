## Requirements
- macOS 26 or later
- Apple silicon

## Install
1. Open `Wadjet-<version>.dmg` and drag Wadjet into Applications.
2. Open Wadjet. This build isn't notarized, so macOS blocks it the first time. Go to System Settings › Privacy & Security, scroll down, and click **Open Anyway** next to Wadjet.
   Or run this in Terminal: `xattr -dr com.apple.quarantine /Applications/Wadjet.app`
3. Wadjet asks for Screen Recording permission. Grant it, then quit and reopen Wadjet.
